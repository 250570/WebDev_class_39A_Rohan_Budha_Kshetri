# Web Development Class Assignment

## Assignment 1 - HTML Portfolio

This assignment is an HTML portfolio webpage.

### Requirements

1. Boss's name using h1
2. Boss's position using h2
3. Internal navigation links
4. Introduction section
5. Bold, italic, underlined and highlighted text
6. Subscript and superscript
7. Boss's image with caption
8. Experience using an ordered list
9. Skills using a table
10. Projects using an unordered list
11. YouTube video


## Assignment 2 - CSS Portfolio
This assignment is a CSS-styled HTML portfolio webpage.

### Requirements
1. Boss's name and position centered
2. Navigation links styled
3. Header and navigation background color
4. Introduction paragraph justified
5. Boss's image centered with rounded edges
6. Experience entries with different font weights
7. Skills table styled
8. Projects section styled
9. YouTube video centered and resized
10. Contact form styled
11. Responsive webpage
